## Purpose

为 Vela 的桌面设置与内置应用提供一个按作用域隔离、可持久化、可迁移的轻量配置层，避免各应用自行复制配置读写与迁移逻辑。

## ADDED Requirements

### Requirement: 配置按作用域隔离

系统 SHALL 提供 `system` 作用域与 `apps/<id>` 作用域，并让每个作用域句柄只读写自身。不同作用域之间 MUST 互不影响。作用域标识 MUST 校验格式；包含路径分隔符、`..` 或空段的标识 MUST 被拒绝。内置应用属于可信代码，本变更不实现运行时 ACL；VPK 不获得配置对象。

#### Scenario: 系统与两个应用互不覆盖

- **WHEN** 系统作用域与两个不同应用作用域分别写入同名键
- **THEN** 三者读取到的值互不影响

#### Scenario: 作用域句柄不提供跨作用域入口

- **WHEN** 应用持有自身作用域句柄
- **THEN** 该句柄只暴露自身作用域的读写接口，不存在指向其他作用域的入口，其他应用的值保持不变

#### Scenario: 非法作用域标识被拒绝

- **WHEN** 作用域标识包含 `/`、`..`、反斜杠或空段
- **THEN** 创建或访问该作用域失败，且不产生 VFS 文件

### Requirement: 配置持久化到 VFS

配置 SHALL 通过 VFS 持久化，每个作用域对应一个 JSON 文件。重启或刷新后 MUST 恢复最后一次成功写入的值。文件不存在时 SHALL 返回默认值；文件损坏或 JSON 解析失败时 MUST 回退默认值，且不得使桌面启动失败。

#### Scenario: 刷新后恢复

- **WHEN** 用户修改系统设置或应用偏好后刷新桌面
- **THEN** 对应作用域读取到最后一次成功写入的值

#### Scenario: 配置文件缺失

- **WHEN** 作用域从未写入过
- **THEN** 读取返回默认值，且不创建空文件

#### Scenario: 配置文件损坏

- **WHEN** VFS 中的配置文件不是合法 JSON 或不符合配置信封结构
- **THEN** 读取回退默认值，桌面继续启动，原文件不被覆盖

### Requirement: 默认值、schema 与失败原子性

写入 SHALL 先合并默认值并校验已知字段。校验失败 MUST 返回错误并保持当前内存值与 VFS 文件不变。未知字段 MUST 保留，以支持版本前后兼容。

#### Scenario: 部分更新保留其他字段并补默认

- **WHEN** 用户只修改一个设置项
- **THEN** 其他已存值与默认值保持，写入后读取结果包含完整配置

#### Scenario: 非法值被拒绝且状态不变

- **WHEN** 写入的值不符合 schema
- **THEN** 写入返回错误，内存值与 VFS 文件仍是上一次成功写入的内容

#### Scenario: 未知字段跨读写保留

- **WHEN** 配置文件包含当前版本未识别的字段后再次写入已知字段
- **THEN** 未识别字段仍被保留

### Requirement: 版本化迁移

配置文件 SHALL 包含版本号。加载旧版本时 MUST 按注册的迁移步骤转换，成功后写回新版本；迁移失败时 MUST 保留原文件并回退默认值。迁移 MUST 幂等。

#### Scenario: 旧版本升级一次

- **WHEN** 配置文件版本低于当前版本且存在对应迁移步骤
- **THEN** 读取得到迁移后的值，文件版本更新为当前版本

#### Scenario: 迁移失败保留原文件

- **WHEN** 迁移步骤抛出错误
- **THEN** 原文件保持不变，读取回退默认值并报告迁移失败

#### Scenario: 重复启动不重复迁移

- **WHEN** 已迁移的配置在后续启动中再次加载
- **THEN** 不再执行迁移写入，读取值保持稳定

### Requirement: 变更订阅与重置

配置读取 SHALL 可订阅。写入或重置后 MUST 通知订阅者一次；值未变化时 MUST NOT 通知。订阅 MUST 可取消。重置 MUST 恢复默认值并持久化。

#### Scenario: 写入触发一次通知

- **WHEN** 一次写入改变了配置值
- **THEN** 订阅者收到一次通知，且读取到新值

#### Scenario: 相同值不通知

- **WHEN** 写入的值与当前值深度相等
- **THEN** 不触发通知

#### Scenario: 取消订阅后不再通知

- **WHEN** 订阅者取消订阅后再次发生写入
- **THEN** 已取消的订阅者不再收到通知

#### Scenario: 重置恢复默认并持久化

- **WHEN** 用户重置某个作用域
- **THEN** 内存与 VFS 均恢复为默认值，订阅者收到一次通知

### Requirement: 桌面设置兼容迁移

现有桌面设置 SHALL 保持相同语义：主题色、壁纸、Marketplace URL 与快捷键。公开的更新、快捷键设置与重置行为保持不变。升级后首次启动 MUST 把 localStorage 旧键中的设置迁移到 `system` 作用域，且 MUST 保留旧键；迁移 MUST 只执行一次；已有 `system` 配置 MUST 优先于旧键内容。

#### Scenario: 旧设置首次迁移

- **WHEN** 设备上只有 localStorage 旧键且 `system` 作用域为空
- **THEN** 系统作用域得到旧键中的主题色、壁纸、Marketplace URL 与快捷键

#### Scenario: 已有系统配置时不覆盖

- **WHEN** `system` 作用域已有配置且 localStorage 旧键仍有内容
- **THEN** 以系统作用域配置为准，不执行覆盖写入

#### Scenario: 旧键保留可回滚

- **WHEN** 迁移完成
- **THEN** localStorage 旧键仍保留原值，不被删除或清空

#### Scenario: 设置界面刷新后恢复

- **WHEN** 用户通过设置界面修改主题色、壁纸与快捷键后刷新
- **THEN** 设置界面显示修改后的值，快捷键绑定立即生效

### Requirement: 第三方 VPK 不获得配置访问

本变更中 VPK 沙箱 MUST 不提供配置读写通道；只有桌面注入的内置应用服务可以访问配置层。

#### Scenario: VPK 无法访问配置

- **WHEN** 第三方 `.vpk` 应用尝试读取或写入桌面配置
- **THEN** 该应用没有可用接口，操作失败且桌面配置不变
